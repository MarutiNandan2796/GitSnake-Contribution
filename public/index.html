📚 GitSnake Pro Integration Guide

1. Automated Daily Generation

You can set up a GitHub Action to automatically regenerate your snake every night and push it to a branch (e.g., output), allowing you to embed a completely self-updating SVG!

# .github/workflows/generate.yml
name: Generate Snake

on:
  schedule:
    - cron: "0 0 * * *" # Daily
  workflow_dispatch:

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - name: Generate SVG
        uses: Platane/snk@v3 # (Or GitSnake Pro Action)

2. Command Line Generator

Generate high-quality animated SVGs and static PNG files directly from your terminal. Set the GITHUB_TOKEN environment variable to download real user profiles.

# Install dependencies
npm install

# Run command
npm run generate -- --user MarutiNandan2796 --skin dragon --theme matrix --png

# Options
--skin [classic|dragon|robot|pacman|ghost|fox|cat|dinosaur]
--theme [matrix|cyberpunk|neon|sakura|fire|galaxy...]

3. API Query Formats

Host GitSnake Pro on your own server (Vercel, Render, etc.) and hotlink the animated image directly into your README files using dynamic endpoints.

# Markdown Embed
![GitSnake](http://localhost:3000/api/preview?user=MarutiNandan2796&skin=robot&theme=cyberpunk)

# API Query Variables
?user=<name>
&skin=[classic|dragon|robot|...]
&theme=[matrix|cyberpunk|...]
&speed=120
&foodGlow=true
&particles=true
